# BMSTU Mail Bot

Telegram-бот для уведомлений о новых письмах на почте `student.bmstu.ru`.
Каждый студент подключает свой ящик через команду в боте и получает уведомления с темой письма и ссылкой на веб-почту.

---

## Архитектура

```
.
├── main.go                  — точка входа, конфиг из env
├── internal/
│   ├── bot/bot.go           — Telegram-бот, обработка команд, polling-цикл
│   ├── mailer/imap.go       — IMAP-клиент (student.bmstu.ru:993)
│   └── storage/storage.go  — хранение пользователей в JSON
├── data/
│   └── users.json           — данные пользователей (создаётся автоматически)
├── Dockerfile
├── docker-compose.yml
└── .env                     — токен бота (не коммитится)
```

**Поток работы:**
1. Студент вводит `/login почта пароль` — бот проверяет IMAP-соединение и сохраняет учётные данные
2. Каждые `POLL_INTERVAL` бот подключается к IMAP каждого пользователя и ищет письма с UID больше последнего известного
3. При нахождении новых писем отправляет уведомление с темой и ссылкой на веб-почту

**Стек:** Go 1.21, `go-imap`, `telegram-bot-api/v5`, Docker

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/login почта пароль` | Подключить почту и начать получать уведомления |
| `/status` | Проверить статус подключения |
| `/logout` | Отключить уведомления |

## Запуск

### Требования
- Docker и Docker Compose на сервере

### 1. Клонировать репозиторий

```bash
git clone https://github.com/твой_юзер/tg-mail-bot.git
cd tg-mail-bot
```

### 2. Создать `.env`

```bash
cp .env.example .env
nano .env
```

Заполнить:

```
BOT_TOKEN=токен_от_BotFather
POLL_INTERVAL=2m
```

### 3. Запустить

```bash
docker compose up -d
```

### 4. Проверить

```bash
docker compose ps       # статус контейнера
docker compose logs -f  # логи в реальном времени
```

| Перезапустить | `docker compose restart` |
| Логи | `docker compose logs -f` |
| Обновить после изменений | `git pull && docker compose up -d --build` |

## Безопасность

- Токен бота и учётные данные пользователей **не попадают в git** (`.gitignore`)
- Файл `data/users.json` хранит пароли в открытом виде — держи сервер закрытым
- При вводе `/login` пароль виден в чате — рекомендуй пользователям удалять это сообщение после отправки
