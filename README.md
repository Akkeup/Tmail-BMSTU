# BMSTU Mail Bot

Telegram-бот для уведомлений о новых письмах на почте `student.bmstu.ru`.
Каждый студент подключает свой ящик через команду в боте и получает уведомления с темой, отправителем и вложениями прямо в Telegram.

---

## Архитектура

```
.
├── main.go                  — точка входа, конфиг из env
├── internal/
│   ├── bot/bot.go           — Telegram-бот, обработка команд, polling-цикл
│   ├── mailer/ximss.go      — XIMSS-клиент (CommuniGate Pro, student.bmstu.ru)
│   └── storage/             — SQLite-профили и кеш почтовых метаданных
├── data/
│   ├── bot.db               — SQLite-профили и кеш последних писем
│   └── users.json           — резервный файл миграции старых профилей
├── Dockerfile
├── docker-compose.yml
└── .env                     — токен бота (не коммитится)
```

**Поток работы:**
1. Студент вводит `/login` — бот запрашивает почту и пароль по отдельности
2. Бот проверяет подключение к серверу через XIMSS API и сохраняет учётные данные (пароль шифруется AES-256-GCM)
3. Каждые `POLL_INTERVAL` бот проверяет входящие каждого пользователя
4. При нахождении новых писем отправляет короткое уведомление `📬 Получено новое письмо!`
5. Письма доступны в разделе `📬 Почта`: быстрый локальный список из 6 последних писем с пагинацией по 4; тело и вложения загружаются только при открытии письма

**Стек:** Go 1.21, CommuniGate Pro XIMSS API, `telegram-bot-api/v5`, Docker

## Интерфейс бота

После запуска бот показывает постоянную клавиатуру:

| Кнопка | Описание |
|---|---|
| `📅 Расписание` | Расписание на всю неделю |
| `📬 Почта` | Список входящих писем |
| `📅 Сегодня` | Занятия на сегодня |
| `📆 Завтра` | Занятия на завтра |
| `🗓 Неделя` | Расписание на всю неделю |
| `📋 Меню` | Дополнительные разделы |

В меню доступны:

- `📅 Другой день` — расписание по дате `ДД.ММ.ГГГГ`;
- `⚙ Настройки` — изменение учебной группы;
- `🏃 Физкультура` — данные о посещаемости из ЛКС;
- `🗺 Карта` — пока информационная заглушка.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/login` | Подключить почту (пошаговый ввод: сначала адрес, затем пароль) |
| `/status` | Проверить статус подключения |
| `/logout` | Отключить уведомления |

## Запуск

### Требования
- Docker и Docker Compose на сервере

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Akkeup/test.git
cd test
```

### 2. Создать `.env`

```bash
cp .env.example .env
nano .env
```

Заполнить:

```
BOT_TOKEN=токен_от_BotFather
SECRET_KEY=любая_случайная_строка_для_шифрования
POLL_INTERVAL=2m
```

### 3. Запустить

```bash
docker compose up -d
```

### 4. Проверить

```bash
docker compose ps       # статус контейнера
docker compose logs -f  # логи в реальном времени
```

### Локальный запуск на macOS

Для локальной работы сначала собери бинарник:

```bash
go build -o bot .
./bot
```

Чтобы бот не зависел от открытого терминала и автоматически перезапускался,
используй подготовленный LaunchAgent:

```bash
mkdir -p ~/Library/LaunchAgents
cp launchd/com.bmstu.baumanets.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.bmstu.baumanets.plist
```

Перед установкой проверь путь `/Users/akkeup/test` в plist. Проверка состояния:

```bash
./scripts/healthcheck.command
```

## Безопасность

- Токен бота хранится только в `.env` и не попадает в git
- Профили и кеш почтовых метаданных хранятся в `data/bot.db`; пароли внутри БД зашифрованы AES-256-GCM ключом из `SECRET_KEY`
- Старый `data/users.json` сохраняется как резервная копия и мигрируется в SQLite при первом запуске
- При вводе пароля через `/login` рекомендуй пользователям удалять то сообщение после отправки
