# BMSTU Mail Bot

Telegram-бот для уведомлений о новых письмах на почте `student.bmstu.ru`.
Каждый студент подключает свой ящик через команду в боте и получает уведомления с темой, отправителем и вложениями прямо в Telegram.

---

## Архитектура

```
.
├── main.go                  — точка входа, конфиг из env
├── internal/
│   ├── bot/bot.go           — Telegram-бот, обработка команд, polling-цикл
│   ├── mailer/ximss.go      — XIMSS-клиент (CommuniGate Pro, student.bmstu.ru)
│   └── storage/storage.go  — хранение пользователей в JSON (пароли зашифрованы)
├── data/
│   └── users.json           — данные пользователей (создаётся автоматически)
├── Dockerfile
├── docker-compose.yml
└── .env                     — токен бота (не коммитится)
```

**Поток работы:**
1. Студент вводит `/login` — бот запрашивает почту и пароль по отдельности
2. Бот проверяет подключение к серверу через XIMSS API и сохраняет учётные данные (пароль шифруется AES-256-GCM)
3. Каждые `POLL_INTERVAL` бот проверяет входящие каждого пользователя
4. При нахождении новых писем отправляет уведомление с темой, отправителем и вложениями одним сообщением

**Стек:** Go 1.21, CommuniGate Pro XIMSS API, `telegram-bot-api/v5`, Docker

---

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/login` | Подключить почту (пошаговый ввод: сначала адрес, затем пароль) |
| `/status` | Проверить статус подключения |
| `/logout` | Отключить уведомления |

## Запуск

### Требования
- Docker и Docker Compose на сервере

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Akkeup/test.git
cd test
```

### 2. Создать `.env`

```bash
cp .env.example .env
nano .env
```

Заполнить:

```
BOT_TOKEN=токен_от_BotFather
SECRET_KEY=любая_случайная_строка_для_шифрования
POLL_INTERVAL=2m
```

### 3. Запустить

```bash
docker compose up -d
```

### 4. Проверить

```bash
docker compose ps       # статус контейнера
docker compose logs -f  # логи в реальном времени
```

## Управление

| Действие | Команда |
|---|---|
| Запустить | `docker compose up -d` |
| Остановить | `docker compose down` |
| Перезапустить | `docker compose restart` |
| Логи | `docker compose logs -f` |
| Обновить после изменений | `git pull && docker compose up -d --build` |

---

## Безопасность

- Токен бота хранится только в `.env` и не попадает в git
- Пароли пользователей хранятся в `data/users.json` в зашифрованном виде (AES-256-GCM, ключ из `SECRET_KEY`)
- При вводе пароля через `/login` рекомендуй пользователям удалять то сообщение после отправки
